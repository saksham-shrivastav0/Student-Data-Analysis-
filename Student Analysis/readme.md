# 📊 Student Performance Analysis System

A data analysis project built using **NumPy** and **Pandas** to analyze student performance, generate insights, and make basic predictions.

---

## 🚀 Features

- 📂 Load and clean raw student data
- 🧹 Handle missing values and duplicates
- 🏆 Identify topper based on average score
- ⚠️ Detect weak students
- 📈 Generate performance insights
- 🔮 Predict next test score (based on previous tests)

---

## 🧠 Tech Stack

- Python 🐍
- NumPy 🔢
- Pandas 🐼

## ⚙️ How to Run

1. Clone the repository:

```
git clone https://github.com/saksham-shrivastav0/student-analysis.git
```

2. Navigate to the project folder:

```
cd student-analysis
```

3. Install dependencies:

```
pip install pandas numpy
```

4. Run the project:

```
python main.py
```
